# DotMaker アプリケーション仕様

## 1. アプリケーション概要
アップロードした画像をレトロなドット絵（ピクセルアート）風に変換・編集できる画像加工アプリケーション。

## 2. コア機能要件
### 2.1. ドット化（モザイク化）処理機能
- スライダーUIを用いて、ドットの粗さを調整できる。

### 2.2. カラー・階調設定（減色処理）
- **カラーモード**: 16色, 256色, 4096色, 65536色
- **モノクロモード**: 2階調, 8階調, 16階調, 256階調

### 2.3. 画像編集機能
- **トリミング**: 画角やサイズでの切り抜き。
- **リサイズ**: 出力サイズの変更。

### 2.4. ファイル入出力
- **入力フォーマット**: JPEG, PNG, GIF, TIFF, HEIC, BMP
- **出力フォーマット**: PNG, JPEG

## 3. その他
- デスクトップアプリ (Tauri v2) として構築し、アドホック署名を用いてビルドする。

## 4. 実装上の定義
### 4.1. ドット化
- ドットの粗さ = ブロック一辺のピクセル数（1〜64）。各ブロックを平均色（RGBA、四捨五入）で塗りつぶし、出力サイズは入力と同じ。端の半端なブロックはその範囲内の平均とする。

### 4.2. 減色方式
| モード | 方式 |
|---|---|
| 16色 | CGA 16色パレットへの最近傍（RGB二乗距離）マッピング |
| 256色 | RGB332（R8・G8・B4段階） |
| 4096色 | RGB444（各16段階） |
| 65536色 | RGB565（R32・G64・B32段階） |
| モノクロN階調 | BT.601 輝度を N 段階に均等量子化 |

- 処理順は「トリミング → リサイズ → ドット化 → 減色」。アルファ値は保持する。

### 4.3. トリミング
- 画角プリセット（自由・1:1・4:3・3:4・3:2・2:3・16:9・9:16）を選ぶと、画像中央から最大の範囲を切り抜く。
- X・Y・幅・高さを数値で指定できる。画角固定中は幅と高さが連動する。範囲は常に画像内に補正する。

### 4.4. リサイズ
- 出力の幅・高さ（1〜8192px）を指定する。縦横比の保持を選べる（基準はトリミング後のサイズ）。
- 補間はバイリニア（Triangle）。リサイズ後にドット化するため、ドットの粗さは出力画像のピクセル数基準となる。

### 4.5. エクスポート
- PNG（透明を保持）または JPEG（品質 1〜100、既定 90。透明部分は白で合成）で保存する。
- 保存先は保存ダイアログで選ぶ。拡張子がフォーマットと合わない場合は末尾に補う（例: `photo` → `photo.png`）。
- 既定のファイル名は「元ファイル名_dot.拡張子」。

### 4.6. 画像の読み込み（HEIC・向き情報）
- HEIC/HEIF はファイル先頭の `ftyp` ボックスのメジャーブランド（heic, heix, hevc, hevx, heim, heis, hevm, hevs, mif1, msf1）で判定し、macOS 標準の ImageIO でデコードする（外部ライブラリ不要）。
- 向き情報（回転・反転）を反映して読み込む。HEIC は ImageIO が、JPEG / TIFF / PNG などは EXIF の Orientation を読み取って反映する。向き情報が壊れている場合は回転しない。
- 元画像のプレビューも Rust 側でデコードした PNG を表示し、変換処理と見た目を一致させる。
- テスト用フィクスチャ（HEIC・向き付き JPEG/TIFF）は `src-tauri/tests/fixtures/generate_fixtures.swift` で再生成できる。

### 4.7. Drag & Drop・コピー＆ペースト
- ウィンドウ全体に画像ファイルをドロップすると読み込む（ドラッグ中は枠と案内を表示）。画像以外はエラーメッセージを表示する。
- ⌘V でクリップボードの画像（画像データ、または Finder でコピーした画像ファイル）を読み込む。テキストのペーストは妨げない。
- 「クリップボードにコピー」で変換後の画像を PNG としてクリップボードへコピーする。
- HTML5 の Drag & Drop でファイル内容を受け取るため、Tauri のウィンドウ設定で `dragDropEnabled: false` としている。
